<summary>⚙️ How to enable the animated snake (one-time setup)</summary>

<br/>

1. Add the included `.github/workflows/snake.yml` file to your **profile repo** (`mrnazmul68/mrnazmul68`).
2. Go to your repo → **Settings → Actions → General → Workflow permissions** → set to **Read and write permissions**.
3. Go to the **Actions** tab and manually run the **"Generate Snake"** workflow once.
4. It will auto-create an `output` branch with the animated SVG, and the image above will start working — it also re-runs automatically every day.
